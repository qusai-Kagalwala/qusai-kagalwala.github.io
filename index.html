02 Work

Selected work.

Things I've built, some professionally and some for myself. Open any project to see how it works.

  • 01

    DoclyPersonal

    Offline Windows app that makes photos, signatures and PDFs portal-ready for Indian exam and government forms.

    PythonPySide6PillowOpenCVpypdf
    How it works+

    What I built

    • Presets for SSC, UPSC, IBPS, Passport Seva, NTA and college portals
    • Smart crop and compression to an exact KB limit
    • Signature background cleaner
    • PDF merge, split, reorder and compress-to-size, with batch mode

    Decisions I made

    • Fully offline, with no uploads and no telemetry, because these are people's ID documents
    • Originals are never modified; every output is a new file
    • Python + PySide6 to ship a native .exe quickly with mature imaging libraries
    v1.0 in development View code
  • 02

    HisaabPersonal

    Offline-first money diary for India: log an expense in three taps and see what's safe to spend today.

    React NativeExpoTypeScriptSQLiteZustandGemini
    How it works+

    What I built

    • Three-tap logging, plus typing "chai 20" or logging from a home-screen widget
    • A single "safe to spend today" number with the maths explained
    • Buckets, goals, bills, borrow and lend, and monthly insights
    • Ask questions in English, Hindi or Hinglish, answered from your own data

    Decisions I made

    • Money is stored as integer paise, never floating point
    • History is never edited: changes are corrections, and balances are always recomputed
    • AI is optional and only explains; it never invents numbers, and only totals leave the phone
    • About 325 unit tests on the money engine, with strict TypeScript
    Android APK View code
  • 03

    Helpdesk platformProfessional

    An AI-assisted helpdesk for an IT and AV team: fix it yourself, request equipment, or raise a ticket.

    ReactNode.jsPostgreSQLSocket.IOPWAWeb Push
    How it works+

    What I built

    • AI first-level troubleshooting before a ticket is ever raised
    • Service requests, tickets and an equipment inventory lifecycle
    • Three roles with department-level scoping
    • Real-time updates and push notifications, as an installable app

    Decisions I made

    • A real PWA wrapped as a trusted web activity (TWA), not a WebView, so notifications arrive even when the app is closed
    • Sign-in goes through the organisation's existing login, so no passwords are stored
    • Designed from day one for Windows Server / IIS hosting
    • Replaces a desktop-only legacy system that needed too much data entry

  • 05

    Data sync & APIProfessional

    A service that keeps a PostgreSQL copy of a SQL Server table in sync and shares it through an API.

    Node.jsExpressSQL ServerPostgreSQLcron
    How it works+

    What I built

    • Scheduled sync every few hours, keyed on a unique member ID
    • Rate-limited, IP-restricted API for other internal apps
    • A dashboard to switch the scheduled job on and off

    Decisions I made

    • Sync into PostgreSQL rather than querying the source live, so other apps never load the main database
    • Upserts on a stable key, so re-runs are safe
